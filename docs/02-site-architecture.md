## الصفحة الرئيسية — هيكل الأقسام (بالترتيب)

1. **Hero** — صورة/فيديو placeholder + عنوان + CTA «اكتشفي المجموعة»
2. **شريط ثقة** — 4 أيقونات (COD، شحن، أصلي، دعم)
3. **لماذا نما** — 3 بطاقات (تركيبة، ثقة، عروض)
4. **المنتجات الثلاثة** — بطاقات مع نجوم + عرض من 199 ر.س
5. **UGC / فيديوهات** — شبكة 6 placeholders (TikTok/Snap style)
6. **شهادات** — carousel من `testimonials.json`
7. **العلم والعناية** — قسم «كيف نختار منتجاتنا» (سلطة)
8. **FAQ** — 8 أسئلة
9. **CTA نهائي** — زر للمجموعة
10. **Footer**

**تخطيط desktop للأقسام المتناوبة:**
- قسم زوجي: نص يمين + صورة يسار
- قسم فردي: صورة يمين + نص يسار
- موبايل: عمود واحد (صورة فوق النص)

## السلة `CartDrawer`

- قائمة عناصر (منتج + عرض + سعر)
- **بانر عروض:** «وفّري أكثر — أضيفي قطعة ثانية بـ 279 بدل 398»
- أزرار ترقية سريعة: ترقية لـ double/triple لكل سطر
- المجموع + «دفع عند الاستلام»
- CTA: **«إتمام الطلب الآن»** → `CheckoutModal`

## نافذة الدفع `CheckoutModal`

- ملخص الطلب + ندرة («سنؤكد خلال 30 دقيقة»)
- حقل الاسم
- حقل الجوال (سعودي فقط)
- إثبات اجتماعي مصغّر: «انضمي لـ +12,000 عميلة»
- زر: **«أكّدي طلبك — الدفع عند الاستلام»**

## Upsell `UpsellModal` (10–15 ثانية)

- منتج مرتبط بـ 99 ر.س فقط
- عدّاد تنازلي
- «نعم أضيفي» / «لا شكراً»
- عند الإغلاق أو انتهاء الوقت → `/thank-you?order_id=...`

## صفحة الشكر

- رسالة دافئة + رقم الطلب
- خطوات ما بعد الطلب (اتصال تأكيد، شحن 2–5 أيام)
- تتبع Purchase pixel + CAPI
- لا تكرار checkout
