# الملخص التنفيذي — نما للجمال (Sahtk)

## الهدف التجاري

متجر **DTC** باللغة العربية (لهجة سعودية) لبيع 3 منتجات دروبشيبينغ **بأسعار مرتفعة** عبر:
- علامة تبدو **مالكة للمنتج** (ليست متجر عام)
- سلطة، إثبات اجتماعي، شهادات، لغة **مركز التسويق المعتمد** (موثوق لدى نساء السعودية)
- **الدفع عند الاستلام فقط** — لرفع التحويل وتقليل احتكاك الدفع
- عروض كمية لرفع **AOV** (متوسط قيمة الطلب)
- **Upsell 99 ر.س** مرة واحدة بعد إتمام الطلب (المكان الوحيد للخصم)

## العلامة التجارية

| العنصر | القيمة |
|--------|--------|
| الاسم العربي | **نما للجمال** |
| الاسم الإنجليزي (تحت الشعار) | **YOUR HELT** |
| الشعار في الهيدر | دائرة بلون العلامة + حرف **S** داخلها، بجانبها نص الشعار بخط أنيق |
| الجمهور | نساء السعودية 25–45 (عناية، جمال، عافية، ثقة بالذات) |
| النبرة | دافئة، واثقة، علمية-عاطفية، سعودية — بدون وعود طبية مبالغ فيها |

## المنتجات (3)

1. **علكة بلاتينية ضد تساقط الشعر** — `platinum-hair-gum`
2. **مشروب غازي مضاد للتجمد** — `anti-freeze-sparkling`
3. **بودرة مضادة للتجمد** — `anti-freeze-powder`

## التسعير (لكل منتج — ر.س)

| العرض | الكود | السعر | الكمية |
|-------|------|-------|--------|
| قطعة واحدة | `single` | 199 | 1 |
| قطعتان | `double` | 279 | 2 (افتراضي — الأكثر طلباً) |
| ثلاث قطع | `triple` | 349 | 3 |

**Upsell بعد الطلب:** 99 ر.س لمنتج مرتبط — **10–15 ثانية** عدّ تنازلي قبل الانتقال لصفحة الشكر.

## تدفق التحويل (مختصر)

```
صفحة منتج → اختيار عرض → CTA يفتح السلة
→ السلة تعرض العروض الترويجية
→ CTA إتمام → نافذة منبثقة (اسم + جوال سعودي)
→ إرسال طلب + Webhook + CAPI Purchase
→ Upsell 99 ر.س (10–15 ث)
→ صفحة شكر
```

## قيود قانونية/تسويقية (إلزامية)

- لا تستخدم: «يعالج»، «يشفي»، «نتيجة مضمونة 100%» للمنتجات غير مرخصة طبياً.
- استخدم: «يساعد»، «يدعم»، «روتين عناية»، «تجربة عملائنا».
- اذكر أن المنتجات **مكملات/عناية** وليست بديلاً للاستشارة الطبية عند الحاجة.
- صفحات: سياسة الخصوصية، الشحن، الاسترجاع، الشروط — مطلوبة للثقة والإعلانات.
